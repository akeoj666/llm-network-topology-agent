# IP/VLAN 编址规划书

> 每次 `gen.py` 生成 `.pkt` 时，**配套产出一份 `{UID}_编址规划.md`**，
> 里面是给人看的那一份：一张分层规划图 + 三张表。
> `.pkt` 是给机器用的，点开才知道长什么样；实验报告、给同学讲方案、贴作业时用的就是这份。

## 一、里面有什么

| 章节 | 内容 |
|---|---|
| §1 规划图 | ASCII 分层图：从上游/核心到汇聚、接入、终端，每段链路标出「两端口 ↔ 网段」 |
| §2 IP 编址表 | 逐接口：地址、掩码、所属网段、CIDR、用途（业务网关/业务/互联/备用）、VLAN、备注 |
| §3 VLAN 与网关表 | VLAN 号、名称、网段、网关（单臂子接口或 SVI）、承载接口清单 |
| §4 设备与策略 | 每台设备：层次、角色、型号、跑的路由协议、承担的关键策略（默认路由 / ACL） |
| §5 怎么读 | 口径说明（层次怎么推出来的、用途怎么判的） |

## 二、层次是**推**出来的，不是写死的

| 判据 | 归到 |
|---|---|
| 有默认路由的路由器 | 边界/出口层 |
| **默认路由下一跳所在的那台路由器** | ISP/上游层（画在最上面，头上是「上游网络 / Internet」） |
| 其余路由器 | 核心/骨干层 |
| 交换机带 trunk 口或单臂子接口 | 汇聚层 |
| 其余交换机 | 接入层 |
| PC / 服务器 | 终端层 |

「默认路由的下一跳属于谁」是这么找的：拿下一跳地址去所有设备的接口地址里比对，
命中哪台，那台就是上游。**这个判据是数据驱动的**——不是把设备名硬编码成 R1/R2。

## 三、拿 UC-07 举例

```
上游网络 / Internet
│
● R2  (Router-PT-Empty)   ← ISP/上游；静态路由
   │ FastEthernet2/0 ↔ FastEthernet3/0  202.96.0.0/30
   ├─ R1  (Router-PT-Empty)   ← 边界/出口；静态路由；默认路由 202.96.0.2；ACL 100（FastEthernet2/0.30 in）
   │  │ FastEthernet2/0 ↔ FastEthernet0/24
   │  └─ SW0  (2960-24TT)   ← 汇聚
   │     │ FastEthernet0/1 ↔ FastEthernet0  192.168.30.0/24
   │     ├─ PC0  (PC-PT)   ← 终端
   │     │ FastEthernet0/2 ↔ FastEthernet0  192.168.30.0/24
   │     ├─ PC1  (PC-PT)   ← 终端
   │     │ FastEthernet0/3 ↔ FastEthernet0  192.168.40.0/24
   │     ├─ PC2  (PC-PT)   ← 终端
   │     │ FastEthernet0/4 ↔ FastEthernet0  192.168.40.0/24
   │     └─ PC3  (PC-PT)   ← 终端
   │ FastEthernet3/0 ↔ FastEthernet0  218.75.230.0/24
   └─ SRV0  (PC-PT)   ← 终端
```

对照看：R1 是园区边界（默认路由 + ACL 100 都在这），R2 是它上游的 ISP，
SW0 汇聚两个 VLAN，PC 按 VLAN 分到 192.168.30.0/24 与 192.168.40.0/24。
**和手工画的设计图是同一个意思，但这是从 DSL 算出来的，改一处地址图会跟着变。**

## 四、几条边边角

1. **图是树，拓扑未必是树**。三角互联（UC-01/UC-82 的 R0—R1—R2）里有一条边不在主干路径上，
   会单独列在图下方的「没画出来、但存在的链路」里，**不藏**。
   UC-82 那条正是实验 4-11 要验证的绕行链路 `10.0.0.0/30`。
2. **二层链路也要标网段**。PC—交换机那种连接在 DSL 里没有 `subnet`，
   但从主机地址能反推出落在哪个网段，图上照样标出来（`192.168.30.0/24`）。
3. **VLAN 名字与网关**从 `vlans:` 与 `subnets[].vlan` 两处合并，
   网关优先取子网里声明的那个（那才是真实网关地址）。
4. **`shutdown` 的口标成「备用」**，没配地址的口标成「未配地址」，都不假装它可用。

## 五、怎么用

```cmd
python gen.py examples\uc07.yaml -o out --confirm CONFIRM   :: 连规划书一起出
python tools\plan.py examples\uc07.yaml                     :: 只补跑规划书
python tools\plan.py --all                                  :: examples/ 与 out/ 里全跑一遍
python tools\test_plan.py                                   :: 七组断言
```

`out/` 下现在有 14 份规划书（UC-01/02/03/05/06/07/80/81/82/91~95）。
