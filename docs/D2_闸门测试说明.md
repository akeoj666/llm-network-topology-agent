# D2 闸门测试说明（装好 PT 后 10 分钟做完）

> 这一步决定后面 12 天怎么排。四个文件是**递进**的，任何一个失败都能立刻定位原因，
> 不用盲猜。请按顺序打开，用手机拍一张照（或截图）发我。

## 准备

装 Packet Tracer **8.2.x**（推荐 8.2.2，与种子文件版本一致；装 9.x 也能打开，会自动升级格式）。
装好后先打开 `seeds/base_rip_3r3sw6pc.pkt` 确认能正常显示 3 台路由器 + 3 台交换机 + 6 台 PC。

## 四个文件

文件都在 `D:\bouns\out\`。

### ① gate0_roundtrip.pkt —— 原样重编码
**做什么**：双击打开。
**看什么**：能不能正常显示拓扑（3 台路由、3 台交换机、6 台 PC、11 条线）。
**判定**：打不开或空白 → 编码器有问题（或 PT 版本不兼容），后面全停，我来修。

### ② gate1_rename.pkt —— 只改了设备名
**做什么**：打开，看第一台路由器旁边显示的名字。
**看什么**：应该是 **R1-EDGE**（原来叫 Router0），左下角那台 PC 应该叫 **PC-A**（原来叫 PC0）。
**判定**：名字变了 → 改 NAME 安全；没变或打不开 → 设备标识改不得。

### ③ gate2_config.pkt —— 改名 + 注入配置 + 改 PC 的 IP + 挪位置
**做什么**：
1. 打开，看 **R1-EDGE** 是不是被挪到了画布中间偏上（坐标 200,260），**PC-A** 挪到了左下（120,340）
2. 双击 R1-EDGE → CLI → 回车，敲 `show running-config`
3. 双击 PC-A → Desktop → IP Configuration

**看什么**：
- `show run` 里第一行应该是 `hostname R1-EDGE`，并且能看到 `ip address 10.99.0.1 255.255.255.252` 和 `router rip` / `version 2`
- PC-A 的 IP 应该是 **192.168.16.10**，掩码 **255.255.255.192**，网关 **192.168.16.62**
- 设备位置应该变了

**这一项是整个方案的核心**：如果配置真的被 PT 认了，那我们就能一句话生成"带完整配置的 pkt"。
如果名字变了、位置变了，但配置没生效 → 说明 PT 只吃 GUI 里敲的配置，不吃文件里的 RUNNINGCONFIG，
那就改成"生成 pkt 骨架 + 一键粘贴配置"（还能拿 C1 的分，只是没那么惊艳）。

### ④ gate3_pruned.pkt —— 删掉了 4 台 PC
**做什么**：打开。
**看什么**：应该只剩 **3 路由器 + 3 交换机 + 2 台 PC（PC0、PC1）**，链路 7 条，没有报错、没有孤儿连线。
**判定**：能正常打开 → 我们的"骨架裁剪"能力成立，可以用同一套骨架拼不同规模的拓扑。

## 第二轮：配置到底进没进去（gate4 / gate5）

第一轮已经很清楚了：改名、挪位置、改 PC 的 IP/掩码、删设备全部生效。唯一没确认的是
**路由器配置**——因为从 XML 换成 PT 的 CLI 时，口令模式、接口名任何一处不对都会让结果看起来像"没生效"。

### 正确的查看姿势（关键）

PT 里打开设备后提示符是 `R1-EDGE>`（用户模式，`>`），这个模式下 `show running-config` 是不允许的，
会直接报 `% Invalid input detected`。**必须先敲 `enable` 进 `#` 模式**：

```
enable
show ip interface brief
show running-config | include hostname
```

### ⑤ gate4_patched.pkt —— 最保守的注入
在原文件那份 80 行配置上只改 4 个值：`hostname`、`Serial0/0` 的 IP、`Fa2/0` 的 IP、RIP 版本，
再补上 `network` 和 `no auto-summary`。命令集合与原文件完全一致。
**看什么**：`show ip int brief` 里 `Serial0/0` 应是 `10.0.0.29/30`、`FastEthernet2/0` 应是 `192.168.16.1/26`。

### ⑥ gate5_fresh.pkt —— 整段替换
用一段全新的 18 行配置整体替换。接口名已按真实硬件修正（这台路由器插了串口模块，
局域网口是 **Fa2/0**，不是 Fa0/0 —— 上一版 gate2 就栽在这里）。
**看什么**：同上，但 IP 是 `10.99.0.1/30` 和 `192.168.16.1/26`。

> 两个都试，是为了分清责任：gate4 挂了说明 PT 不让我们碰配置；gate4 过、gate5 挂说明
> 只接受"原样微调"，那我们就把生成策略改成"补丁式"（在原配置上打补丁，而不是整段替换）。

## 回报格式

一句话就够：

```
① 正常  ② 名字变了  ③ 配置生效了，IP 也变了  ④ 正常，剩 3R+3SW+2PC
⑤ 补丁式生效  ⑥ 整段替换生效
```

如果某项失败，附一张截图 + PT 版本号（Help → About）。
