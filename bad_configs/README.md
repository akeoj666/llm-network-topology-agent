# C3 的坏配置样本

全部由 `tools/make_bad_configs.py` 从真实生成物里**只改一处**得到，
其余字节与能跑通的配置一致。

| 样本 | 来源用例 | 坏在哪 |
|---|---|---|
| `case1_漏network` | UC-01 | R1 的 router rip 少宣告了 10.0.0.0，R2 学不到行政部网段 |
| `case2_错掩码` | UC-01 | R1 与 R2 之间的 /30 互联口被写成 255.255.255.0 |
| `case3_VLAN未建` | UC-05 | SW0 把端口划进 VLAN 20，但 VLAN 数据库里没有 vlan 20（PT 里 VLAN 20 不出现） |
| `case4_ACL未定义` | UC-07 | R1 的客人子接口挂了 access-group 100，但 ACL 100 的条目全被删了（等于全放行） |
| `case5_地址非法` | UC-01 | R3 的业务口写成网段号 192.168.16.128/26（该网段的网络地址） |
